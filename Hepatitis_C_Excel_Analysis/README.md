Hepatitis C Patient Laboratory Data Analysis and Interactive Dashboard Using Microsoft Excel

1. Project Overview
This project focuses on the analysis of Hepatitis C patient laboratory data using Microsoft Excel. The objective was to clean, organise, analyse and visualise the dataset to identify patterns across different patient diagnostic categories.
The project demonstrates the application of Excel data analysis techniques, from raw data preparation to the development of an interactive dashboard.

2. Dataset Description
The dataset contains:
- 615 patient records
- 14 columns
- Patient demographic information and laboratory test results
- Different diagnostic classifications

The patient categories include:
Category Code     Classification
0                                  Blood Donor
0S                               Suspect Blood Donor
1                                   Hepatitis
2                                   Fibrosis
3                                 Cirrhosis

3. Tools and Techniques Used
Microsoft Excel was the primary tool used for this project.
The following features and techniques were applied:

Power Query: For data cleaning and transformation
Excel Tables: To structure and organise the dataset.
PivotTables: To summarise and analyse the data.
PivotCharts: To present analytical findings visually.
Slicers: To provide interactive filtering of the dashboard by patient category.
Excel Dashboard: To communicate the analysis through visual representations.

4. Project Workflow
The project was organised into five major sections:
1. Raw Dataset: The original dataset before processing.
2. Cleaned Data: The prepared dataset organised into a structured Excel Table.
3. PivotTables: Summarisation and analysis of the data.
4. Power Query: Data transformation and preparation.
5. Interactive Dashboard: Visual presentation of the analysis with a Category slicer.

5. Dashboard Interactivity
The dashboard includes a Category slicer that allows users to filter the analysis by patient classification.
Users can explore the following categories:
- Blood Donor
- Suspect Blood Donor
- Hepatitis
- Fibrosis
- Cirrhosis
This makes it easier to examine the different classifications represented in the dataset.

6. Project Objectives
The major objectives were to:
- Prepare and organise the raw laboratory dataset.
- Apply data cleaning and transformation techniques.
- Summarise laboratory and demographic information.
- Explore patterns across patient categories.
- Develop an interactive dashboard for data presentation.

7. Conclusion
This project demonstrates the use of Microsoft Excel for data preparation, analysis and visualisation.
It provided practical experience in working with a healthcare-related dataset, using Power Query, PivotTables, PivotCharts and Excel dashboard features to transform raw data into a structured analytical presentation.

Tools: Microsoft Excel | Power Query | PivotTables | PivotCharts | Excel Slicers
